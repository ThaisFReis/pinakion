          How the decision is verified

          Pinakion follows the jury’s constitution and its binding to the vote. At the end, this page redoes the checks from the record and shows any divergence. The decision and the check appear separately.

          This session’s rules come from the demo’s configuration. The step count follows the run; it is not an estimate of the time left.

          Secret ballot with Tessera

          The secret ballot uses Tessera, the same author’s earlier module. The case contract accepts the vote only if the voters are exactly the attending jurors.

          Contract and Wasm client at commit 356c22f, used unchanged. Tessera’s code ↗ · Attribution

          Limits of this demonstration
          • Every key is created in this tab and the accounts share one funder. The relayer that would break that link is not built.
          • The circuit’s setup was run by a single party. The system has not been audited.
          • The windows are shortened for the demo; the approved reveal floor is 30 days. The record is public.
          • Closing or reloading the tab stops the run. Use fictional data only, on testnet.
